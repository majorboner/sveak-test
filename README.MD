# SVEAK — тестовое задание

demo: https://majorboner.github.io/sveak-test/

## Количество карточек и пунктов меню
 
Оба значения меняются через константы в `vite.config.js`
 
```js
const TOTAL_CARDS = 65;       // количество карточек
const TOTAL_MENU_BUTTONS = 24;  // количество пунктов меню
```


## Запуск
 
```bash
npm i             # установка пакетов
npm run dev       # http://localhost:5173/sveak-test/
npm run build     # сборка в /dist
```
